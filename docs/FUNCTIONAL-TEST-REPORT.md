## 本轮边界复查

- 图表使用 288 个五分钟时间桶；不补造事件，不用插值制造事件峰值。曲线控制点在相邻真实点区间内，不超出峰值。图表可读记录有上限：最近 512KB、最多 20000 条，超出时明确提示统计不完整。
- 本机命令型 MCP：通过配置改写接入；HTTP MCP：经中转地址接入。仅识别 Agent、登记配置路径或添加 HTTP 服务，并不代表实际调用已经过代理。
- 无默认适配器的产品：可指定受支持结构的 JSON/JSONC/TOML 文件。没有可修改 MCP 设置的产品不可接入。云端 Agent 一般无法访问 127.0.0.1；未提供公网转发或远程部署能力。
- 阻断范围：代理内的 MCP 请求。Agent 绕过代理、直接运行本机命令或使用其他网络连接不在该范围内。行为基线是规则统计，不是可保证准确率的攻击识别模型。
- 54 产品收录不等于 54 产品真实联调；27 默认配置适配器使用隔离样本验证。未安装产品、产品更新后的新配置格式、实际攻击误报/漏报率仍未完成真实环境验收。

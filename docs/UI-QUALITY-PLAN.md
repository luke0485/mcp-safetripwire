# UI 质感改进方案

采用简洁的 Windows 桌面工具风格，统一组件体系后再逐页调整。

1. 视觉层级：浅灰背景、白色内容卡片、1.5px 适中边框；移除卡片内重复方框。红色仅留给阻断和已确认严重事件。
2. 排版：正文 14px、辅助文字 12px、标题 16px；统一 8/16/24px 间距、10px 圆角和 36px 按钮高度。厂商是次要文字，产品名称与图标为主要标识。
3. 首页：紧凑统计条、满宽真实数据图、按 Agent 分组的 MCP 链路。空状态只提供一个添加入口，操作结果直接在当前模块反馈。
4. 交互：120–180ms 的按压、切页、弹窗反馈；支持减少动画设置，不延迟启动或 API 请求。错误保留输入，避免重复弹出打断操作的提示。
5. 验收：720/960/1280px 宽度、中英文、深浅色、键盘导航和高 DPI；每页核对真实空状态、加载、成功、失败与未接入状态。

本轮已完成满宽 5 分钟采样图、柔化线条、基础控件/切页/弹窗动效、44px 关闭按钮、接入能力说明和 WorkBuddy 独立图标。整体排版与反馈系统的统一重做属于下一轮设计工作。
